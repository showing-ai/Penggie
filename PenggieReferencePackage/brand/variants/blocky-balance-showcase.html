Blocky Balance — 把方块感找回来

用户反馈"过于圆角化"。回看原图 DNA，重新校准：保留 pixel-art 方块气质 + 仅做最小 vector polish

设计演化 · 三个阶段

STAGE 1 · ORIGINAL
原始像素企鹅
  • 纯方块 sharp 90°
  • 翅膀矩形凸起 sharp
  • blocky / retro / 8-bit DNA
  • 但: 像素 aliasing 锯齿感强
STAGE 2 · OVER-ROUNDED
过圆版（错了的方向）
  • 身体 rx=10，圆润 mascot 感
  • 翅膀 smooth Q-bump 像吹气球
  • 脸 rx=4，软
  • 丢失原 pixel DNA → "Slack 风吉祥物"
STAGE 3 · JUST RIGHT
校准版（现在）
  • 身体 rx=3 微 chamfer，方形 DNA
  • 翅膀矩形 protrusion + 外角 rx=2
  • 翅膀 7px 宽，小尺寸不消失
  • 单一连续 path → 翅膀和谐连接
  • 脸 rx=2，"monitor 屏幕"感
  • 眼睛 / 鸟喙 sharp（保留 pixel DNA）
  • 整体：blocky-but-polished

逐项对照

元素 Stage 1 原图 Stage 2 过圆 Stage 3 现在 设计理由
身体拐角 sharp 90° rx = 10 rx = 3 仅 vector polish，保留方形 DNA
翅膀形状 矩形 sharp 凸起 Q-curve smooth bump (r=5) 矩形 protrusion + 外角 rx=2 保 blocky 凸起，仅外角微 chamfer
翅膀凸起宽度 ~3 像素 (≈9% body) 5px (8%) 7px (12%) 稍微加大，小尺寸下不消失

脸（显示器）拐角 sharp 90° rx = 4 rx = 2 "monitor 屏幕"感，仅最小软化
