# Penggie Wordmark Design Spec

Penggie uses the existing pixel penguin mark as its primary icon and introduces a new Penggie wordmark. The legacy ShowCLI wordmarks remain reference material only.

## Direction

- Brand name: `Penggie`
- Category: AI agent CLI GUI / developer tool
- Mood: terminal-native, friendly, compact, pixel-aware
- Core motif: pixel penguin mark plus a restrained geometric wordmark

## Canonical Assets

- `penggie-wordmark-horizontal.svg`
- `penggie-wordmark-dark-horizontal.svg`
- `penggie-wordmark-stacked.svg`

## Explorations

- `explorations/penggie-wordmark-01-terminal-mono.svg`: terminal cursor direction
- `explorations/penggie-wordmark-02-pixel-lockup.svg`: pixel underline system
- `explorations/penggie-wordmark-03-prompt-lockup.svg`: explicit `$` prompt cue
- `explorations/penggie-wordmark-04-compact-badge.svg`: dark compact badge
- `explorations/penggie-wordmark-05-lowercase-soft.svg`: softer lowercase direction
- `explorations/penggie-wordmark-06-minimal-type.svg`: type-only minimal mark

## Usage Notes

- Use the canonical horizontal lockup for product chrome, docs, and website headers.
- Use the dark horizontal lockup for social tiles, launch screens, and dark marketing surfaces.
- Use the stacked lockup for centered splash or app-introduction layouts.
- Keep the old `ShowCLI` wordmark files as legacy/reference assets only.
- If these become shipping brand assets, convert live SVG text to path outlines in a final production pass.
