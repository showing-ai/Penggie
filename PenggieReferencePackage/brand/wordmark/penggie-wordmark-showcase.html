Penggie Wordmark

New Penggie lockups based on the validated pixel penguin direction. Legacy ShowCLI wordmarks remain reference-only and are not used as shipping Penggie assets.

Canonical Horizontal

penggie-wordmark-horizontal.svg pairs the existing mark with a compact geometric wordmark for app chrome, docs, and website headers.

Dark Horizontal

penggie-wordmark-dark-horizontal.svg keeps the warmer dark icon treatment for launch, social, and dark marketing surfaces.

Stacked

penggie-wordmark-stacked.svg is built for centered splash moments where the icon needs stronger presence than a horizontal header.

Terminal Mono

A developer-native variant with a visible cursor block. Strong for CLI-adjacent documentation, less friendly as the default product lockup.

Pixel Lockup

Adds a small grid underline to echo terminal cells without building a decorative command parser metaphor into the mark.

Prompt Lockup

Uses a leading $ as an explicit terminal cue. Useful as an exploration, but likely too CLI-specific for the canonical brand.

Compact Badge

A contained dark badge for README headers, previews, and compact product tiles.

Lowercase Soft

A friendlier lowercase direction. It has warmth, but weakens the exact product-name recognition compared with Penggie.

Minimal Type

A type-only fallback for places where the icon would be redundant or too small.
