# Product-Grade UI/UX Implementation Board

This board turns `design.md` into executable milestones. Every row must keep Codex CLI and the embedded Ghostty PTY as the runtime authority; Reading and native UI may only project terminal facts or Display AST evidence.

## Execution Rule

Before changing app code for any row:

1. Identify the OpenSpec task and affected module owner.
2. Record fixture/manual/accessibility/visual evidence expectations.
3. Reject any approach that clones Codex-owned state or forks the user-visible session.
4. Land the smallest verifiable milestone with tests/QA evidence, then commit and push.
